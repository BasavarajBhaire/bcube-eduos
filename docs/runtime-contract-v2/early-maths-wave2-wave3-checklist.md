# Early Maths Adventures LKG — Wave 2 and Wave 3 test checklist

## Wave 2: P020–P028

- P020 Compare Numbers: four complete numeral-pair cards; each row explicitly says greater or smaller.
- P021 Math Stories: three complete scenes, not narrow fragments; one answer set per story.
- P022 2D Shapes: four clean shapes and four clean familiar objects; matching anchors only.
- P023 3D Objects: four clean solids and four familiar objects; matching anchors only.
- P024 Shape Hunt: one large scene plus four target shapes; no mismatched thumbnails.
- P025 Patterns: oral observation only; no answer boxes.
- P026 Complete the Pattern: one missing place and three picture choices per row.
- P027 Position Words: three word choices per scene.
- P028 Directions: visible directional route with start and destination.

## Wave 3: P029–P044

- P029–P034: four large comparison cards; every card has its own deterministic prompt.
- P035 Time Awareness: four large routine scenes and four order responses.
- P036 Sorting: two labelled categories with six movable/classifiable items.
- P037 Classifying: colour × shape matrix with six exact placements.
- P038 Picture Graph: four category rows, visible totals and two comparison prompts.
- P039 Problem Solving: three independent visual problems with task-specific answer sets.
- P040 Maths Around Me: one large scene plus four target cues.
- P041 Maths Review: four distinct quadrants with number, shape, pattern and comparison mechanics.
- P042 Certificate: child name, date and teacher fields; decorative assets do not cover writing zones.
- P043 Reflection: large hero, three skill choices and one oral sentence starter.
- P044 Back Cover: illustration only; no worksheet shell or teacher cue.

## Global gates

- No clipped or partial assets.
- No generic response circles or boxes.
- Response-control count matches the page contract.
- No Parent Panel or Home Connection.
- Missing named assets fail closed.
- Output remains TEST_CANDIDATE until visual review is complete.
