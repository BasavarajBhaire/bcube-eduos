# SOP-ACA-001 — Annual Academic Planning

**Status:** Draft v0.1  
**Owner:** Academic Head

## Purpose
Establish the approved academic plan before the academic year begins.

## Procedure
1. Confirm programme levels, operating calendar and instructional days.
2. Review approved curriculum scope and learning outcomes for each level.
3. Map curriculum/modules/books to available instructional periods.
4. Reserve orientation, progress-review, PTM, event and teacher-development windows.
5. Identify material, workbook, classroom-resource and training dependencies.
6. Review load balance so curriculum completion does not require rushed delivery.
7. Publish the controlled annual academic calendar and programme maps.
8. Define change-control ownership for mid-year revisions.

## Controls
- Only approved curriculum versions may be scheduled.
- Calendar changes affecting families or curriculum require documented approval and communication.
- Events should not repeatedly displace core learning without a recovery plan.

## Evidence
Approved academic calendar, programme curriculum map, resource plan, teacher-development calendar and revision history.

## KPIs
- plan approved before academic start
- curriculum mapped to available teaching days
- material readiness before first use
- unplanned academic-calendar disruption
