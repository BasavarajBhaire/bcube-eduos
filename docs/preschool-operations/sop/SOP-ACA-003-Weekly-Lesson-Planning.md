# SOP-ACA-003 — Weekly Lesson Planning

**Status:** Draft v0.1  
**Owner:** Class Teacher; reviewed by Academic Coordinator

## Purpose
Translate the monthly curriculum plan into executable, age-appropriate daily learning experiences.

## Weekly plan must define
- programme / class and week
- learning objectives
- curriculum / book / page references where applicable
- teacher-led activity
- child action / observable evidence
- materials
- vocabulary / concepts
- differentiation or additional support
- observation focus
- home connection where appropriate

## Procedure
1. Review the monthly plan and prior-week observations.
2. Select the next approved learning objectives and source assets.
3. Sequence activities from introduction to guided practice to independent evidence.
4. Balance communication, literacy/numeracy, creativity, movement, social-emotional and Future Skills experiences appropriate to the programme.
5. Identify materials and prepare them before the activity day.
6. Define what the teacher should observe—not only what should be completed.
7. Add support/enrichment adaptations without lowering the intended learning purpose.
8. Submit for coordinator review within the branch planning cadence.
9. Incorporate review feedback before delivery.

## Quality checks
- clear child action
- one understandable primary objective per focused activity
- developmentally appropriate duration and complexity
- no unnecessary worksheet dependency
- safe materials and setup
- sufficient active participation
- traceability to approved curriculum

## Evidence
Approved weekly plan plus teacher notes on material changes or learning adaptations.
