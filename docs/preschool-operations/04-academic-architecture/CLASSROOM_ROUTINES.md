# Nursery, LKG & UKG Classroom Routines

**Status:** Draft framework — exact timings should be configured by programme and branch calendar.

The routines below define **sequence and design intent**, not rigid minute-by-minute mandates.

## Nursery 3+

Priority: security, communication, sensory exploration, movement, routines, play and short guided learning experiences.

Typical sequence:

`Arrival & settling → Welcome / talk → Movement → Short focused learning → Exploration / play → Snack & hygiene → Story / communication → Creative / sensory experience → Outdoor / gross motor → Reflection & dispersal readiness`

Design rules:
- shorter focused segments
- high movement and manipulation
- simple one-step/two-step instructions
- generous transition time
- minimal passive seatwork
- frequent language modelling and emotional reassurance

## LKG 4+

Priority: foundational literacy/numeracy, communication, self-management, curiosity, creativity and structured exploration.

Typical sequence:

`Arrival → Welcome circle → Language / literacy → Movement break → Early maths → Snack / hygiene → Future Skills / thematic exploration → Creative / fine-motor activity → Story / speaking → Outdoor / physical → Reflection`

Design rules:
- concrete before abstract
- short guided practice followed by child action
- visual and manipulative supports
- structured speaking opportunities
- early independence in routines

## UKG 5+

Priority: school-readiness foundations, reasoning, communication, independence, collaborative learning and Future Skills.

Typical sequence:

`Arrival → Planning / welcome → Language & communication → Literacy → Movement → Mathematics → Snack / hygiene → Future Skills / inquiry → Creative design / project work → Story / reflection → Outdoor / physical → Closure`

Design rules:
- increasingly independent task completion
- explanation of thinking, not only answers
- collaborative tasks where suitable
- multi-step but age-appropriate directions
- observation of readiness without turning preschool into primary-school drill

## Common non-negotiables

Every programme should include movement, communication, social interaction, child choice/exploration, hygiene routines and opportunities for teachers to observe individual children.
