# CHK-OPS-002 — School Closing

**Status:** Draft v0.1  
**Owner:** Branch Closing Lead

## Student reconciliation
- [ ] All scheduled children accounted for as departed, absent or otherwise formally resolved.
- [ ] No child remains in classroom, washroom, activity, play, transport waiting or other child area unnoticed.
- [ ] Dispersal exceptions resolved/escalated.

## Academic / classroom
- [ ] Classroom learning materials secured/reset.
- [ ] Sensitive student records not left exposed.
- [ ] Devices/equipment stored or powered down as required.
- [ ] Next-day priority requirements communicated.

## Safety / facility
- [ ] Washrooms and child areas checked.
- [ ] Windows/doors/access points checked according to facility procedure.
- [ ] Electrical/appliance shutdown completed where applicable.
- [ ] Waste/cleaning handover completed.
- [ ] Safety or maintenance defects logged and escalated.
- [ ] Security/alarm/locking process completed by authorized role.

## Administration
- [ ] Attendance reconciled.
- [ ] Incidents/health events documented and follow-ups assigned.
- [ ] Parent follow-ups requiring action assigned.
- [ ] Fee/admission exceptions requiring next-day action recorded.
- [ ] Visitors/contractors cleared from controlled areas.
