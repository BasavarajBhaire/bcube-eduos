# CHK-ADM-001 — Admission Readiness

**Status:** Draft v0.1  
**Owner:** Admissions / Branch Administration

Use before marking a new admission operationally ready.

- [ ] Application/admission decision recorded.
- [ ] Student identity/profile details captured to the approved minimum standard.
- [ ] Parent/guardian contact details verified through the approved process.
- [ ] Emergency contact information captured.
- [ ] Authorized pickup information captured.
- [ ] Relevant health/allergy/emergency information captured through approved forms.
- [ ] Required consent/acknowledgement records completed.
- [ ] Programme/class/academic year assigned.
- [ ] Approved fee terms recorded.
- [ ] Required initial payment/reconciliation status recorded.
- [ ] Parent orientation completed or scheduled.
- [ ] Student start date confirmed.
- [ ] Classroom/teacher informed using appropriate need-to-know information.
- [ ] Student record available in attendance/dispersal processes before first day.
- [ ] Any special operational requirement has an owner and documented plan.
- [ ] Admission readiness reviewed by authorized role.

> Exact mandatory documents and consent language must be defined by approved local policy and applicable requirements.
