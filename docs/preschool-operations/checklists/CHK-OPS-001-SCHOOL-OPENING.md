# CHK-OPS-001 — School Opening Readiness

| Field | Value |
|---|---|
| Owner | Branch Head / delegated opening lead |
| Frequency | Every operating day before student arrival |
| Version | 0.1 Draft |

## Readiness checklist

| # | Check | Complete | Exception / action |
|---|---|---|---|
| 1 | Entry/access and designated child arrival area are safe and ready | ☐ | |
| 2 | Classrooms inspected for obvious hazards and readiness | ☐ | |
| 3 | Washroom/hygiene areas checked | ☐ | |
| 4 | Drinking water / approved child-use facilities checked | ☐ | |
| 5 | First-aid resources accessible to authorized staff | ☐ | |
| 6 | Emergency exits/routes are not obstructed | ☐ | |
| 7 | Attendance mechanism is available | ☐ | |
| 8 | Teaching/activity materials required for opening sessions are ready | ☐ | |
| 9 | Known maintenance/facility hazards are corrected, isolated or escalated | ☐ | |
| 10 | Required staff coverage / supervision readiness confirmed | ☐ | |

A failed mandatory safety item must not be ignored simply to open on time. Apply the relevant safety escalation and determine whether the affected area/activity can operate safely.
