# CHK-OPS-010 — Branch Pre-opening Readiness

**Status:** Draft v0.1  
**Owner:** Launch Lead / Branch Head

Use `Pass / Fail / N/A`, evidence reference, owner and due date for each applicable control.

## 1. Governance & approvals
- [ ] Branch launch owner assigned
- [ ] Approved operating capacity recorded
- [ ] Required local approvals / professional reviews tracked
- [ ] Insurance / contractual requirements confirmed where applicable
- [ ] Emergency contacts established

## 2. Facility
- [ ] Approved layout delivered / as-built variances reviewed
- [ ] Classrooms safe, clean and ready
- [ ] Child movement routes clear
- [ ] Entry / visitor control ready
- [ ] Washrooms operational and child-appropriate
- [ ] Water / power / ventilation operational
- [ ] Storage ready; restricted materials secured
- [ ] Play/activity areas inspected
- [ ] Signage installed
- [ ] Cleaning and waste process active

## 3. Safety & emergency
- [ ] Opening safety checklist tested
- [ ] First-aid resources ready
- [ ] Emergency / evacuation procedure briefed
- [ ] Staff know incident escalation route
- [ ] Arrival / dispersal simulation completed
- [ ] Authorized pickup control tested
- [ ] Emergency contact records available to authorized staff
- [ ] Critical safety findings closed

## 4. People
- [ ] Leadership roles filled
- [ ] Required teacher/support roles filled against approved capacity
- [ ] Onboarding complete
- [ ] Required verification/background checks complete
- [ ] Code of conduct / safeguarding induction complete
- [ ] Academic induction complete
- [ ] Opening roster and absence coverage ready

## 5. Academic
- [ ] Programme / class structure confirmed
- [ ] Curriculum / book materials available
- [ ] First-month academic plan ready
- [ ] First-week lesson plans ready
- [ ] Classroom learning zones prepared
- [ ] Teacher observation / assessment process briefed
- [ ] Parent progress communication process understood

## 6. Admissions & parents
- [ ] Enquiry and admissions workflow active
- [ ] Enrolled-student roster reconciled
- [ ] Required admission records checked
- [ ] Parent orientation scheduled/completed as applicable
- [ ] Arrival / dispersal instructions communicated
- [ ] Fee status visible to authorized staff
- [ ] Complaint / escalation channels communicated

## 7. Technology & data
- [ ] Connectivity tested
- [ ] Staff accounts and RBAC tested
- [ ] Attendance workflow tested
- [ ] Parent communication workflow tested
- [ ] Finance permissions tested
- [ ] Sensitive record handling controls active
- [ ] Outage fallback documented
- [ ] CCTV/access systems tested where implemented

## 8. Finance / procurement
- [ ] Approved fee structure configured
- [ ] Receipt/payment process tested
- [ ] Petty-cash / expense controls briefed where used
- [ ] Critical vendors active
- [ ] Opening inventory verified
- [ ] Asset register initiated

## 9. Marketing / launch
- [ ] Branch information consistent across approved channels
- [ ] Campus visit process ready
- [ ] Opening communication approved
- [ ] No unsupported claims in launch materials

## 10. Launch authorization
- [ ] Critical findings = 0
- [ ] High findings have owner/date and accepted launch disposition
- [ ] Branch Head sign-off
- [ ] Academic sign-off
- [ ] Operations/safety sign-off
- [ ] Launch authorization recorded
